# 나의 약속 챌린지

학생이 12주 동안 학습·생활 과제를 실천하며 왕궁, 성, 목장, 대저택, 아파트, 전원주택, 카페 또는 돈 모으기 미션을 성장시키는 웹앱입니다.

## 중요한 저장 방식

- 학생 자료는 Supabase 없이 각 컴퓨터의 브라우저에 저장됩니다.
- 학교 공용 컴퓨터 한 대를 공식 기록기기로 사용하는 것을 권장합니다.
- 관리자 화면에서 매주 백업파일을 내려받아 보관하세요.
- 관리자 비밀번호는 `6673`입니다.

## GitHub에 올리기

1. 이 ZIP 파일의 압축을 풉니다.
2. GitHub에서 새 저장소를 만듭니다.
3. 압축을 푼 폴더 안의 파일과 폴더를 모두 업로드합니다.
4. `Commit changes`를 누릅니다.

중요: ZIP 파일 자체를 올리지 말고, 반드시 압축을 푼 뒤 `app`, `public`, `package.json` 등이 저장소 첫 화면에 보이도록 올리세요.

## Vercel에 배포하기

1. Vercel에서 `Add New` → `Project`를 누릅니다.
2. 위에서 만든 GitHub 저장소를 선택합니다.
3. Framework Preset이 `Next.js`인지 확인합니다.
4. Root Directory는 변경하지 않습니다.
5. 별도의 환경변수는 입력하지 않습니다.
6. `Deploy`를 누릅니다.

## 컴퓨터에서 실행하기

```bash
npm install
npm run dev
```

배포용 확인은 `npm run build`로 할 수 있습니다.
